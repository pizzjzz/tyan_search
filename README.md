# anime-scanner-bot

Telegram-бот — аналог Google Lens для аниме. Определяет персонажа по скриншоту
(имя, аниме, архетип) и находит информацию по имени персонажа или названию тайтла.
Работает в личных чатах и группах. Self-hosted: собирается и запускается локально
или в Docker, всё настраивается через один файл `.env`.

---

## Возможности

- **Поиск по картинке.** Отправьте скриншот из аниме — бот распознает персонажа и покажет
  карточку: имя, название аниме и архетип.
- **Поиск по имени.** `/find Taiga Aisaka` (или по-русски `/find Тайга Айсака`) —
  фото персонажа, список аниме и архетип.
- **Поиск по названию аниме.** `/find A Silent Voice` — информация о тайтле.
- **Работа в группах.** Команды, обращение через `@имя_бота`, ответ на сообщение бота,
  распознавание фото прямо в чате.
- **Архетип персонажа** (опционально, включается/выключается в конфиге).
- **Транслитерация.** Русский ввод автоматически переводится в ромадзи.
- **Русская локализация.** Ответы переводятся на русский: имя персонажа вида
  «Хитори Гото (Hitori Gotou)», названия аниме (через словарь устоявшихся названий
  + автоматический перевод) и биография. При недоступности переводчика — fallback
  на оригинал.
- **Устойчивость к сбоям.** Несколько источников данных с fallback, JSON-логирование,
  защита от паник.

## Как это работает

```
Пользователь ──► Telegram Bot API (long polling)
                     │
                     ├── фото ──► AnimeTrace (нейросеть: имя персонажа)
                     │              └─ если не нашёл ──► trace.moe (аниме по кадру)
                     │
                     ├── /find ──► AniList (персонажи/аниме, без ключей)
                     │              └─ если не нашёл ──► Jikan / MyAnimeList
                     │
                     └── результат: имя + фото + тайтл + архетип ──► пользователю
```

Используются **четыре внешних сервиса**:

| Сервис | Назначение | Ключ |
|---|---|---|
| **AnimeTrace** (`animetrace.go`) | Распознаёт **персонажа** по изображению (нейросеть) | не нужен |
| **trace.moe** (`tracemoe.go`) | Запасной путь: определяет **аниме** по кадру | опционально |
| **AniList** (`anilist.go`) | Основной источник данных о персонажах/аниме (GraphQL) | не нужен |
| **Jikan** (`jikan.go`) | Запасной источник (поверх MyAnimeList) | не нужен |

Единый контракт `AnimeProvider` и агрегатор с fallback (`provider.go`) скрывают детали
API: при сбое основного источника автоматически используется запасной.

## Русская локализация

Все карточки персонажей выводятся на русском в формате:

```
Хитори Гото (Hitori Gotou)

Архетип: Shy — застенчивый и скромный персонаж

Аниме:
• Одинокий рокер!
• Медленная петля

Хитори Гото — застенчивая старшеклассница, научившаяся играть на гитаре...
```

Как это устроено:

- **Имя** — переводится из японского оригинала (кандзи/катакана) — это даёт
  самую точную транслитерацию («後藤ひとり» → «Хитори Гото»);
- **Названия аниме** — сначала проверяется словарь устоявшихся русских названий
  (`localization.go`, `knownTitleRu` — «где принято»), при отсутствии — автоперевод;
- **Описание** — переводится автоматически;
- **Архетип** — русская подпись уже встроена (`archetype.go`).

Перевод использует бесплатный публичный эндпоинт Google Translate (`translation.go`),
без API-ключей: результаты кэшируются, одновременные запросы ограничены. Если
переводчик недоступен (нет сети/лимит) — бот подставляет оригинал и продолжает работать.

## Требования

- **Go 1.21+** (для локального запуска) **или** **Docker / Docker Compose**.
- Доступ в интернет (бот ходит по HTTPS к Telegram и API аниме-сервисов).
- Файл `.env` с токеном Telegram-бота.

## Быстрый старт

### 1. Получить токен бота

Откройте Telegram → найдите **@BotFather** → отправьте */newbot* → укажите имя и username.
BotFather пришлёт токен вида `1234567890:AAHxxx...`.

### 2. Создать конфиг

```bash
cp .env.example .env
```

Отредактируйте `.env` и вставьте токен в `TELEGRAM_BOT_TOKEN=`.

### 3a. Запуск в Docker (рекомендуется)

```bash
docker compose up -d --build
```

Логи в реальном времени:

```bash
docker compose logs -f
```

Остановка:

```bash
docker compose down
```

### 3b. Локальный запуск без Docker

```bash
go run .
```

Сборка бинарника:

```bash
go build -o anime-scanner-bot .
./anime-scanner-bot
```

Бот запустится лонг-поллингом и будет слушать сообщения. В логах появится
`bot_started` с username бота.

## Конфигурация (файл `env`)

Все настройки — в файле `.env`. Шаблон — [`.env.example`](.env.example).

| Переменная | Обязательно | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | ✅ | Токен бота от @BotFather. Без него бот не запустится. |
| `TRACEMOE_API_KEY` | ❌ | Ключ trace.moe (выше лимиты). Пустое значение — работает с лимитом ~10 запросов/мин. |
| `ARCHETYPE_ENABLED` | ❌ | Архетип персонажа. `true` — показывать, `false` — скрыть. По умолчанию `true`. |

> В Docker токены можно передать и напрямую, без правки файла: `docker run -e TELEGRAM_BOT_TOKEN=...`
> или добавив строки в раздел `environment:` `docker-compose.yml`. Переменные окружения имеют
> приоритет над значениями из `.env`.

**Безопасность:** `.env` содержит секреты и не попадает в git (см. `.gitignore`) и в Docker-образ
(см. `.dockerignore`). Коммитить можно только `.env.example` — в нём нет реальных ключей.

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие и краткая справка |
| `/help` | Подробная справка по командам |
| `/find <имя>` | Карточка персонажа или информация об аниме |
| `/search` | Ответьте ей на сообщение с фото — распознать кадр |
| `/select <N>` | Выбрать персонажа из списка кандидатов |

**Группы:**

- `/find Имя` — работает прямо в чате;
- `@имя_бота /find Имя` или `@имя_бота Имя` — обращение к боту по имени;
- просто отправьте скриншот — бот распознает;
- ответьте текстом на сообщение бота (например, с именем персонажа).

## Логирование

Бот использует стандартный пакет `log/slog` и пишет **строго JSON в `os.Stdout`** —
это удобно смотреть через `docker compose logs -f` и фильтровать.

| Уровень | События | Ключевые `msg` |
|---|---|---|
| `INFO` | Действия пользователей, события бота | `user_message`, `user_callback`, `bot_started`, `bot_stopping` |
| `WARN` | Ошибки Telegram API (например, бот заблокирован) | `telegram_api_error` |
| `ERROR` | Ошибки сторонних API, паники, фатальные ошибки старта | `provider_request_error`, `character_card_fetch_error`, `panic_recovered`, `config_error`, `bot_startup_error` |

Примеры:

```json
{"time":"2026-09-14T12:00:00Z","level":"INFO","msg":"user_message","user_id":123456,"chat_id":-100111,"username":"jojo","text":"/find Taiga Aisaka"}
{"time":"2026-09-14T12:00:01Z","level":"WARN","msg":"telegram_api_error","chat_id":123456,"error":"Forbidden: bot was blocked by the user"}
{"time":"2026-09-14T12:00:02Z","level":"ERROR","msg":"provider_request_error","provider":"jikan","endpoint":"https://api.jikan.moe/v4/characters?q=Taiga","status":429,"error":"jikan вернул статус 429"}
```

Полезные команды:

```bash
docker compose logs -f                 # лента в реальном времени
docker compose logs | grep ERROR       # только системные ошибки
docker compose logs | grep WARN        # проблемы Telegram API
```

Просмотр логов без Docker:

```bash
./anime-scanner-bot | jq .              # если установлен jq
```

### Ротация логов

В `docker-compose.yml` ограничен размер логов:

- `max-size: "10m"` — максимум 10 МБ на файл;
- `max-file: "3"` — хранится до 3 файлов.

## Docker: как устроен образ

- **Двухстадийная сборка:** бинарник собирается в `golang:1.21-alpine`, а в итоговый образ
  попадает только статический бинарник + `alpine` с `ca-certificates`. Итоговый образ ~10 МБ.
- **No secrets:** `.env` не копируется в образ (`.dockerignore`) и монтируется/передаётся
  только при запуске.
- **Безопасный запуск:** бот работает от непривилегированного пользователя `appuser`.
- **Мгновенный перезапуск:** `restart: unless-stopped`.

## Возможные проблемы

| Симптом | Решение |
|---|---|
| `config_error: не найден файл .env...` | Создать `.env` из `.env.example` и заполнить токен |
| `bot_startup_error: токен не прошёл проверку` | Проверить токен в `.env` у @BotFather; при утечке — `/revoke` |
| Бот молчит на сообщения в группе | Добавить бота **администратором** и включить громкость (антспам-режим) |
| Лимиты Jikan (429/504) | Ничего делать не нужно: автоматически сработает fallback на AniList |
| `no matching result` у trace.moe | Изображение вне аниме-каталога; попробуйте другой кадр |
| Слишком много логов в группе | В `telegram.go` в `logUserActivity` можно ограничить логирование только командами |
